## 1. AI 智能问数平台

**项目背景**

为业务团队提供自然语言查询数据库的能力，让非技术人员可以直接通过对话完成数据获取。

**项目职责**

- 架构设计：NL2SQL、SQL 安全校验、查询权限控制
- RAG 增强：表结构、字段说明、历史查询样例
- 后端实现：基于 Spring Boot + Python 双语言服务

**技术栈**

`Spring Boot` · `Python` · `LangChain` · `向量数据库` · `MySQL` · `Redis`

**核心问题**

- 大模型生成的 SQL 存在语法与权限风险
- 表/字段命名歧义导致生成准确率低

**解决方案**

- 引入 SQL 解析器 + 注入校验 + 权限映射
- 通过 RAG 注入表结构文档 + 字段注释
- 引入查询样例 few-shot

**最终结果**

自然语言查询准确率从 30% 提升到 75%。

## 2. RAG 知识库系统

**项目背景**

搭建企业级 RAG 知识库，对接多源异构文档（PDF / Word / Markdown / Confluence），支持语义检索 + 大模型回答。

**项目职责**

- 文档处理流水线：解析 → 切片 → Embedding → 索引
- 检索增强：BM25 + 向量混合检索 + 重排序
- 工程化：增量更新、权限隔离、引用溯源

**技术栈**

`Python` · `LangChain` · `LlamaIndex` · `Milvus` · `Elasticsearch` · `MinIO`

**核心问题**

- 文档切片粒度与召回率的平衡
- 答案需要明确引用来源（hallucination 风险）

**解决方案**

- 切片策略：标题分块 + 滑动窗口 + 关键句提取
- 引用溯源：每个 chunk 带源文档元信息，回答时强制引用

**最终结果**

百万级文档场景下 P95 检索延迟 < 200ms，召回率 92%。

## 3. AI 图像识别服务

**项目背景**

面向工业场景的图像识别服务，部署在边缘设备，支持离线/在线两种工作模式。

**项目职责**

- 模型选型与压缩（YOLO 系列 / 蒸馏）
- 推理服务化（ONNX Runtime / TensorRT）
- 边缘端部署（K3s / GPU 共享）

**技术栈**

`Python` · `PyTorch` · `ONNX` · `TensorRT` · `K3s` · `Prometheus`

**核心问题**

- 模型在 GPU 资源受限场景下推理延迟高
- 多模型部署资源竞争

**解决方案**

- 模型蒸馏 + 量化（FP32 → INT8）
- 多模型 GPU 共享 + 动态批处理
- 边缘端通过 K3s 统一编排

**最终结果**

单卡可同时跑 8 路识别任务，P95 延迟 < 80ms。

## 4. 一体化集成平台

**项目背景**

企业内多系统集成平台，统一管理 API 网关、消息总线、任务调度、可观测性。

**项目职责**

- 整体架构设计
- 网关、消息、调度核心模块开发
- 制定团队规范与开发模板

**技术栈**

`Spring Cloud` · `Spring Cloud Gateway` · `RocketMQ` · `XXL-JOB` · `Nacos` · `Sentinel`

**核心问题**

- 多团队协作下的服务治理
- 复杂业务链路的可观测性

**解决方案**

- 服务注册 / 配置 / 限流统一通过 Nacos + Sentinel
- 全链路 SkyWalking 追踪
- 统一网关层做协议转换与鉴权

**最终结果**

承载日均 1.2 亿次 API 调用，链路追踪覆盖率 100%。

## 5. 云原生基础设施

**项目背景**

从零搭建企业云原生基础设施，包括容器平台、可观测体系、CI/CD 流水线。

**项目职责**

- Kubernetes 多集群管理
- GitLab CI / GitHub Actions 流水线设计
- 监控告警体系（指标 / 日志 / 链路）

**技术栈**

`Kubernetes` · `K3s` · `Docker` · `GitHub Actions` · `Prometheus` · `Loki` · `Tempo`

**核心问题**

- 边缘机房资源受限，无法上完整 K8s
- 监控系统对业务侵入大

**解决方案**

- 核心机房用标准 K8s，边缘机房用 K3s 轻量化方案
- 监控侧统一用 Prometheus + Grafana，通过 OpenTelemetry 接入

**最终结果**

支撑 30+ 业务系统的稳定运行，月度故障率下降 60%。
